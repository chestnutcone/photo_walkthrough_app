# Widget screenshot gallery

Generated by `app/test/gallery/gallery_test.dart` (run `cd app && flutter test --tags gallery test/gallery/gallery_test.dart`). Every image is the real app (real router, screens and theme) rendered in a widget test against a fake API with sample data, at 390 x 844 pt (the handoff frame), 1 px per pt. The app has a single dark theme, so there is no light variant. Key screens are also shown at text scale 2.0. Photos are generated gradients. Accessibility results for the same scenes: [a11y-audit.md](a11y-audit.md).
